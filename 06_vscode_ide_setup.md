# Configuration et Personnalisation de l'IDE Visual Studio Code

## Paramétrage de l'Environnement
Visual Studio Code a été configuré pour répondre aux standards de développement multi-langages (HTML, CSS, JavaScript, PHP).

## Extensions et Fonctionnalités Clés
- **Internationalisation :** Installation du module linguistique `French Language Pack for Visual Studio Code`.
- **Productivité Front-End :** Intégration de l'extension `Live Preview` pour l'exécution d'un serveur local de test en temps réel.
- **Portabilité :** Activation de la synchronisation des paramètres via le compte GitHub pour l'uniformisation des postes de travail.
