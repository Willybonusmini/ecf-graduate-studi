# Configuration et Personnalisation de l'IDE Visual Studio Code

## Standardisation de l'Éditeur
Visual Studio Code a été configuré comme l'éditeur principal pour l'ensemble des scripts de développement front-end et back-end.

## Extensions et Fonctionnalités Clés
- **Internationalisation :** Intégration du pack de langue français (`French Language Pack for Visual Studio Code`).
- **Prévisualisation en Temps Réel :** Utilisation de l'extension `Live Preview` pour l'exécution d'un serveur local de test.
- **Gestion de Versions :** Exploitation de l'intégration native de Git pour le suivi de configuration et la synchronisation des branches.
- **Portabilité :** Activation de la synchronisation cloud des préférences via un profil utilisateur centralisé.
