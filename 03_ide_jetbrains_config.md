# Configuration de l'Environnement de Développement Intégré (IDE)

## Choix Technologique
L'IDE principal sélectionné pour le développement de l'application est **PhpStorm** (Suite JetBrains). Ce choix se justifie par son intégration native des écosystèmes PHP, HTML, CSS et JavaScript, et par ses capacités d'analyse de code.

## Procédure d'Initialisation et de Vérification
Avant l'ouverture du projet dans l'IDE, la présence et l'accessibilité de l'interpréteur doivent être garanties au niveau du système d'exploitation.

### Vérification de l'interpréteur PHP (CLI)
Exécution requise dans le terminal système :
```bash
php --version
