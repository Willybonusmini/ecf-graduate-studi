# Dossier Technique : Introduction à la Programmation

## Objectif du Dépôt
Ce dépôt centralise les scripts d'ingénierie logicielle développés dans le cadre de la certification **Développeur Web et Web Mobile (RNCP 37674)**. Chaque module démontre la maîtrise d'un concept fondamental de l'algorithmique, de la sécurité logique et de la persistance des données en mémoire.

## Inventaire des Modules Techniques

### 1. Analyse de Ventes (`analyse_ventes_metier.py`)
* **Compétences Démontrées :** Structures de données dynamiques, List Comprehension, analyse statistique temporelle.
* **Architecture :** Implémentation d'un moteur de filtrage financier basé sur des tableaux unidimensionnels.

### 2. Algorithme de Stock (`algorithme_stock_boulangerie.py`)
* **Compétences Démontrées :** Algorithmique séquentielle, casting de types (`int()`), flux conditionnels stricts.
* **Architecture :** Système d'alerte de rupture de stock basé sur l'évaluation de seuils critiques.

### 3. Logique de Contrôle d'Accès (`controle_acces_logique.py`)
* **Compétences Démontrées :** Évaluation booléenne (`and`, `or`, `not`), optimisation mathématique via les Lois de De Morgan.
* **Architecture :** Moteur de sécurité bloquant les anomalies d'accès selon des règles métier multiniveaux.

### 4. Gestion de Variables et Inventaire (`gestion_variables_metier.py`)
* **Compétences Démontrées :** Typage dynamique, opérateurs d'affectation combinés, lissage de précision (`round()`).
* **Architecture :** Gestion transactionnelle d'un panier e-commerce intégrant la mitigation des dérives de la norme IEEE 754 sur les flottants.
