# Configuration et Personnalisation de Visual Studio Code (IDE)

## Standardisation de l'Éditeur
Visual Studio Code a été configuré comme l'éditeur de code principal pour les tâches d'ingénierie front-end et back-end légères.

## Extensions et Modules Intégrés
- **Pack de Langue :** Localisation de l'interface en français (`French Language Pack for Visual Studio Code`).
- **Prévisualisation :** Extension `Live Preview` pour le rendu dynamique des pages web statiques.
- **Contrôle de Version :** Intégration native de Git pour le suivi des modifications et la synchronisation des dépôts distants.
- **Synchronisation Cloud :** Paramétrage de la synchronisation des profils et des extensions via un compte d'authentification centralisé.
